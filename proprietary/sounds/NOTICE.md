# Sounds in this folder

The five sounds here are not OpenFront's. They were supplied by the
열국쟁패 project owner (KDK221) on 2026-11-13 to replace OpenFront's
proprietary music and alert, which may not be used outside OpenFront:

| File                           | Use                                |
| ------------------------------ | ---------------------------------- |
| `music/menu-theme.mp3`         | Menu music                         |
| `music/gameplay.mp3`           | In-game playlist                   |
| `music/gameplay-2.mp3`         | In-game playlist                   |
| `music/gameplay-3.mp3`         | In-game playlist                   |
| `effects/game-start-alert.mp3` | Lobby "game is starting" chime     |

They keep these paths because the build looks for them here; the
`../LICENSE` text inherited from OpenFront does not describe them.
